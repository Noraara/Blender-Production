# Selecting specialist guidance

Start with the job and its destination. Read an installed specialist’s own instructions and referenced files when the brief calls for them. Follow the upstream installation guide on the current host and check skill discovery before depending on it.

| Task | Relevant guidance |
| --- | --- |
| Reference matching or asset art direction | [arjun988’s library](https://github.com/arjun988/blender-skills), including `blender-director` and the relevant prop, character, or environment specialist. Match camera, outline, large forms, and signature negative spaces. |
| Modeling, texturing, rigging, or animation | [EL4CTEO’s library](https://github.com/EL4CTEO/blender-skills), starting from `blender-core` and the skill for the requested task. Match its documented Blender requirements to the actual version. |
| Asset QA or engine delivery | Check the actual destination requirements. Use the installed `blender-asset-qa` or export specialist where it fits. Review automated findings against the brief. |

Resolve specialist paths through the host’s skill discovery and the author’s documented setup. Read helper source before running it on a project file. If an optional pack is absent, perform the requested checks using Blender's available tools where feasible and identify any specialist check that still needs to run. Respect the project’s authorized scope for assets, tools, and visual review.
