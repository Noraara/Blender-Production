# Blender Production

1. Read the brief and applicable project instructions. Establish the deliverable, intended scale and view, authorized references, and visual review requirements. For a mixed task, accept [the coordinator handoff](references/verification.md#handoff). Use a requested specialist directly when appropriate.
2. For a live edit, use [setup and connection checks](references/installation.md) to inspect the connected Blender version, file, target objects, units, and unsaved changes. Limit changes to the authorized scene and objects. Pick [specialist guidance](references/specialists.md) only when the task needs it.
3. Block out the major forms at scale. Check the intended camera, silhouette, contacts, and negative spaces before adding detail. Keep construction editable. For a small repair, measure the defect before and after and inspect related objects. Use the installed tool schema and Blender API.
4. Inspect the result visually in the intended view and review [applicable asset checks](references/verification.md). For delivery, save the editable source and verify the requested export by reopening or reimporting it in isolation. Report the actual checks, warnings, and any pending review.

For engine import or runtime behavior, use the destination workflow when requested. Follow the project's visual review permissions throughout.
